# データソース

「日本人は何歳まで働くようになったか」探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-06。軸は e-Stat API のメタ取得で確認済み（姉妹編 `japan-data-employment` と同一表）。

## 1. 結論

年齢別就業率を、**時代 / 年齢 / 性**の3ビューで見せる。
一次ソースは総務省「労働力調査」基本集計（年平均・全国）の率表1本。
就業形態・正規非正規は姉妹編 `japan-data-employment` の領域とし、本ツールでは扱わない。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | 労働力調査 基本集計 年平均 | `0002060049` | 年齢×性×年 | 就業率・労働力人口比率・完全失業率 |
| 年齢 | 同上 | `0002060049` | 年齢×性×年 | 年齢プロファイル（選択年の就業率） |
| 性 | 同上 | `0002060049` | 年齢×性×年 | 男女の就業率推移 |

出典表記: 総務省「労働力調査」（e-Stat 経由）。

## 2. 採用データセット（メタ実測）

### `0002060049` — 年齢階級別労働力人口比率，就業率及び完全失業率（1953年～）

- 統計名: 労働力調査 基本集計　全都道府県 全国 年次
- 軸: 表章項目(1: 率) × 産業(1: 全産業) × 性別(3) × 就業状態(3) × 年齢階級(30) × 地域(1) × 年次(73: 1953–2025)
- 就業状態コード: `01` 労働力人口（＝労働力人口比率） / `13` 就業（＝就業率） / `08` 完全失業者（＝完全失業率）
- 性別: `0` 総数 / `1` 男 / `2` 女
- 公表値は％。配信では ÷100 して小数にする。
- 実測: 労働力人口比率・完全失業率は 1953年〜、**就業率は 1968年〜**（それ以前は欠測 `*`）。

### 年齢階級（配信）

重複しない5歳階級＋高齢者合算:

`15～19` `20～24` `25～29` `30～34` `35～39` `40～44` `45～49` `50～54` `55～59` `60～64` `65～69` `70～74` `75歳以上`

加えて合算行: `15歳以上` / `15～64歳` / `65歳以上`。

除外: `15～17` `18・19` `20・21` `22～24` など細分、および `40～54` のような重複合算。

## 3. 見送り（第1版）

| 候補 | 理由 |
| --- | --- |
| `0002060046` 従業上の地位 | 姉妹編 employment の領域 |
| `0003078065` 雇用形態（正規・非正規） | 同上。本ツールは「何歳まで働くか」に集中 |
| `0002060048` 地位×年齢 | 拡張用。第1版は率表で足りる |
| 地域別年平均 | 第1版スコープ外（全国の長期変化に集中） |

## 4. 指標・分母

- **就業率** = 就業者 / 15歳以上人口（公表定義。年齢階級別はその年齢の人口）
- **完全失業率** = 完全失業者 / 労働力人口
- **労働力人口比率** = 労働力人口 / 15歳以上人口（年齢階級別はその年齢）
- 率は小数4桁に丸める。

## 5. 配信ファイル

`scripts/build.ts` → `public/data/`

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `rates.json` | age × sex × year | empRate, unempRate, lfpr | ages |

cube 形式は `dims` + `measures`（行優先）+ 辞書。欠測は `null`。

## 6. 注記（UIに短く出す）

- 2011年: 東日本大震災による調査影響（岩手・宮城・福島の一部）。
- 就業率の公表系列は 1968年〜。それ以前は欠測。
- 労働力人口比率・完全失業率は 1953年〜。
- ベンチマーク人口の切替えにより、接続年次に段差が出ることがある（e-Stat メタの説明を参照）。
